# Setting up hostd

`hostd` is the Sia Foundation's software for storage providers. It stores encrypted data for the network and earns Siacoin (SC) in return. These guides walk you through installing and configuring it.

Choose an install method:

- [Linux](linux/) — apt package (Debian or Ubuntu) or a manual binary. Recommended for a dedicated host.
- [Docker](docker.md)
- [macOS](macos.md) — installed with Homebrew.
- [Windows](windows.md) — desktop app.
