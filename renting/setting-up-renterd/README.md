# Setting up renterd

{% hint style="info" %}
**`renterd` is no longer the preferred way to store data on Sia.** For most users, [Sia Storage](https://sia.storage) (50 GB free, nothing to run) or a self-hosted [`indexd`](../setting-up-indexd/) is a better starting point. `renterd` still works, and these guides remain for existing users.
{% endhint %}

`renterd` is the original all-in-one renter daemon, bundling a wallet, contract management, and an upload/download UI into one program. These guides walk you through installing and configuring it.

Choose an install method:

- [macOS](macos.md) — installed with Homebrew.
- [Linux](linux/) — apt package (Debian or Ubuntu) or a manual binary.
- [Docker](docker.md)
- [Windows](windows.md) — desktop app.
