# Setting up walletd

`walletd` is the Sia Foundation's standalone wallet for Siacoin (and Siafunds). It supports multiple wallets and Ledger hardware wallets. These guides walk you through installing and configuring it.

Choose an install method:

- [Linux](linux/) — apt package (Debian or Ubuntu) or a manual binary.
- [Docker](docker.md)
- [macOS](macos.md) — desktop app.
- [Windows](windows.md) — desktop app.
